# License Management

## License Status

```text
ACTIVE
EXPIRED
REVOKED
```

## License Creation

A license can only be created after application approval.

Example:

```text
Application
APP-2026-000001
     ↓
APPROVED
     ↓
Create License
     ↓
MIC-2026-ONLINE-000001
```

## License Number

Generated by the backend.

Format:

```text
MIC-{YEAR}-{MEDIA_TYPE}-{SEQUENCE}
```

Example:

```text
MIC-2026-ONLINE-000001
MIC-2026-TELEVISION-000002
MIC-2026-RADIO-000003
```

## License Fields

```text
id
license_number

status

```

## APIs

```http
GET  /api/v1/licenses
GET  /api/v1/licenses/:id
POST /api/v1/licenses/:id/revoke
```

## Public Verification

```http
GET /api/v1/public/licenses/verify/:token
```

The public endpoint should return only safe information.

Do not expose:

```text
National ID
Private documents
Password
Sensitive personal information
```

## License Rules

1. License number must be unique.
2. Application can have only one license.
3. License can only be created after approval.
4. License creation must be part of the approval transaction.
5. Revoked licenses cannot be treated as active.
